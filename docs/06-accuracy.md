# 06 · 精度证据

## 验证方法

对同一 prompt 连续采样 3 次 logits，与位精确基线逐元素比较：

- `KL`：相对基线的 KL 散度
- `top-1`：argmax 是否一致
- `maxabsdiff`：逐元素最大绝对差
- `n`：参与比较的元素数

## 结果

| 配置 | KL | top-1 | maxabsdiff | n |
|---|---|---|---|---|
| 位精确基线（bit-exact） | 0 | 一致 | 0 | 248,320 |
| **推荐臂：solution pin 20377 / 20385** | **8.3e−05** | **一致（`a=896 b=896 SAME`）** | 1.74572 | 248,320 |
| 合并臂（pin + `DENSE_TN`） | 2.997e−05 / 2.764e−05 | 一致 | — | — |

## 判读

- 推荐臂的 **top-1 完全一致**，KL 在 1e−04 量级 —— 属于"同精度等级内的内核替换"，不是精度换速度。
- `logits.1` / `logits.2` 与基线存在逐元素差异（因此 maxabsdiff 非 0），但 argmax 与生成结果一致。
- 精度校验脚本：见 `bench/`（`klcheck.py` 风格：读 `logits.0/1/2` 三份二进制 float32 数组）。

## 回滚即恢复位精确

方案只增加一个环境变量。取消该变量后，引擎立即回到位精确路径（同一二进制内两条分支），无需回滚镜像。
