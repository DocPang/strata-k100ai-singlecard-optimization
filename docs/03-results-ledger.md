## 决定性验证：交叉 A/B（2026-10-22 08:10–08:18，同一时间窗交替执行）

| 组 | 第 1 次 | 第 2 次 | 均值 | 组内极差 |
|---|---|---|---|---|
| 控制（基线二进制，无 pin） | 61,272.5 ms | 61,270.9 ms | **61,271.7 ms** | 1.6 ms（0.003%） |
| 实验（新二进制 + pin） | 60,224.8 ms | 60,306.5 ms | **60,265.7 ms** | 81.7 ms（0.14%） |

- **Δ = −1.64%**（prefill），吞吐 2,070.4 → 2,105.1 tok/s
- 控制组两次相差 0.003% → 该时间窗内噪声可忽略，结论成立

```
c1 61272.5  n1 60224.8  c2 61270.9  n2 60306.5   (ms)
```

复现：`bash bench/ab_pin4.sh`

## 一处重要的账目更正

早期日志里的 `sm-c1 / sm-c2 / s2-c1 / s2-c2 / gu-c1 / gu-c2` 被标注为"控制组"，实际它们的 `BASE` 里**已经带了 `STRATA_GEMM_SOL`** —— 它们其实是实验组。这曾导致两个错误推论：

1. 误以为"控制组在 40 分钟内自己漂了 1.5%"（其实是"实验组 60.3k vs 真控制组 61.27k"的对比）；
2. 误以为"pin 在后期失效了"。

全部真控制组读数（无 pin）汇总，一致性很好：

| 读数 | ms | 读数 | ms |
|---|---|---|---|
| gsol-c1 | 61,208.9 | gattr1 | 61,241.6 |
| gsol-c2 | 61,333.7 | gattr2 | 61,280.4 |
| gsol2-c1 | 61,255.0 | cmb-c1 | 61,310.5 |
| gsol2-c2 | 61,341.0 | cmb-c2 | 61,190.0 |
| p4-c1 | 61,272.5 | p4-c2 | 61,270.9 |

均值 ≈ **61,270 ms**，极差 0.25%。实验组（pin）稳定在 **60,22x ~ 60,45x**。

## solution 编号选择

| 编号 | 形状 | 说明 |
|---|---|---|
| 20377 | 2560×6144 | 引擎内略优于 20376（−0.10%），推荐 |
| 20385 | 10240×2560 | N=10240 时最优（−27.1% 于该调用点） |

引擎真实调用参数（`STRATA_GEMM_ATTR` 打印）：`N=2560 K=6144 lda=6144 ldb=6144 ldc=5120`。注意 **`ldc = 2N`**，不是 `N`。
