注意：`bin-new/strata` 是**两个实例共享**的挂载点。因此"换二进制"会影响两台，只换配置才按实例生效。做单实例对照实验时必须把它当成全局变量。

## 上线过程中修正的一个判断

部署前我从日志里怀疑"控制组 40 分钟内漂了 1.5%，所以 −1.56% 是假的"。做交叉 A/B 后发现：那些被标成"控制组"的其实是**已经带 pin 的实验组**（`BASE` 里含 `STRATA_GEMM_SOL`）。真控制组一直稳定在 **61.27 s**，实验组在 **60.2~60.4 s** —— 收益是真的，是我的账目错了，不是数据错了。

教训：**实验脚本里 BASE 变量带没带实验开关，必须在结果表里显式标注**，否则过几小时自己都会认错。
